# ⏱️ Cronômetro em JavaScript

Cronômetro simples com contagem de horas, minutos e segundos, feito para praticar manipulação do DOM e eventos em JavaScript.

🔗 **Acesse aqui:** [Link do Github Pages](https://arthur-ltz.github.io/Timer-JS/)

## Funcionalidades

- **Start / Stop:** inicia e pausa a contagem
- **Reset:** zera o cronômetro e volta ao estado inicial
- Exibição sempre com dois dígitos (`00:00:00`)

## Tecnologias

- HTML
- CSS
- JavaScript

## Ideias por trás do funcionamento

- Usar `setInterval` e `clearInterval` para controlar o tempo
- Selecionar elementos com `querySelector` e alterar o texto com `textContent`
- Formatar números com `padStart`


## Como rodar localmente

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
